# Volume Studio

Open `/volumes-studio/` to author reusable file libraries and publish immutable versions. Aster imports selected versions before Projects use them. Studio uses central accounts and explicit library grants. Non-admin experts can read and review permitted libraries; only administrators can create libraries.
