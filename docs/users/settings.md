# Account settings

[Documentation](../README.md) · User guide

Open **Settings** from the account menu. The dialog leaves your current Project,
conversation and draft selected; on a narrow screen it opens as a full-screen panel.

## Profile, appearance and security

Change your display name, choose system/light/dark appearance and select a neutral,
blue, green or violet accent. Appearance changes preview immediately; check that
the save succeeds. Failed or conflicting saves retain your changes so you can
retry, reapply or revert them.

Use the security controls to change your password or sign out all sessions.
Password changes and all-session sign-out invalidate earlier sessions. Leaving
with an unsaved name or typed password asks whether to discard it. Ordinary logout
does not stop autonomous Project work.

## Resources and usage

**Resources and usage** shows your current allowances and consumption. It is
read-only: ask an administrator to change quotas. A capacity increase may require
both group permission and platform allowance. A lower quota can prevent new work
or resumption while preserving existing files.

## Advanced configuration

**Advanced / Developer** contains optional network and environment selections for
new Projects, along with shared-directory visibility. Despite the label, you do
not need developer access to use the choices granted to your account.

Select an authorized template or keep the inherited default. An unavailable saved
selection may require an administrator to restore access or resolve conflicting
group defaults. Changing this preference does not change existing Projects.

Under **Existing projects**, an explicit network change is a separate operation
and can pause active compute before the Project resumes with the new policy.
The Environment view shows read-only effective versions and update status.
Administrators control publication updates; there is no user self-service runtime upgrade.

Showing shared directories affects browser visibility only. It does not grant or
remove the Agent's underlying access. See [Files](files.md).
