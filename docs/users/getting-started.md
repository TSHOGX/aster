# Get started

[Documentation](../README.md) · User guide

You need your installation's browser address and an account from its administrator.
Aster may appear under your organization's name. The interface supports English
and Chinese; this guide uses the English labels.

## Sign in

1. Open the address supplied by your administrator and sign in.
2. If you received a temporary password, set a permanent password when prompted.
   Temporary passwords expire after 24 hours; the password-setup session lasts
   15 minutes. Ask for a new reset if either expires.
3. Open **Settings** from the account menu to check your profile and appearance.

If sign-in is denied or you cannot create a project, contact your administrator.
Accounts, permissions and resource allowances are managed by the installation.

## Complete your first task

1. Create a Project for a related set of work. Choose a descriptive name.
2. Open **Files** and upload any inputs the Agent will need. Files can be uploaded
   before compute starts.
3. Choose **New Chat**, type a request that names the relevant files, and send it.
   A conversation is created on its first send.
4. Read the reply and expand tool activity when you need to see what happened.
   File links in replies open the file preview.
5. Download outputs from Files, or continue the conversation to refine them.

**Enter** sends; **Shift+Enter** inserts a newline. Ctrl/Cmd+Enter also sends.
Additional conversations in the same Project use the same workspace, so explain
which files they should change. Use separate Projects for unrelated or untrusted work.

## Leave and return

Closing a tab, signing out or hiding a panel does not stop running work. Return to
the Project to read its history and reopen a terminal. Idle compute may pause
automatically; files and history remain accessible. Unsaved file edits need to be
saved or discarded before leaving the editor.

Use explicit Stop, Pause or Delete controls when you intend to change execution
or remove data. Read [Projects and conversations](projects.md) before deleting work.
