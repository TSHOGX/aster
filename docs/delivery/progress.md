## 后续按顺序推进

1. 在仓库之外完成环境私有盘点，按通用清单验证运行产物、数据和写者；不提交现场事实。
2. 准备隔离 amd64构建主机与Ubuntu22.04/24.04资格主机，配置GHCR/Actions权限。构建和验收 runner 必须与生产隔离。
3. 在隔离环境实现并验证site hooks及qualification adapter，产生绑定精确manifest的证据。未完成时流水线保持阻塞，不生成假PASS。
4. 在隔离环境使用一致备份预演，识别脏构建数据库真实结构；不匹配时先审查基线，禁止在生产试迁移。
5. 发布新的rc tag，完成整套制品构建和资格门禁。确认无错误后再按操作手册预约第一套生产维护窗口。
6. 第一套观察至少24小时且覆盖一次自动任务周期，再按同一制品推进第二套。每一步记录操作ID、版本和验收证据。
