# 多环境交付实施记录

目标：Linux amd64 / Ubuntu 22.04、24.04 / systemd；完整 Release + GHCR rootfs；环境主动拉取与离线导入。

## 当前推进方式

- GitHub 托管 runner 承担完整应用/rootfs 构建与自动化制品检查，不要求额外自托管构建/资格平台。
- 完整 Release 发布后，各目标机器在本地私有配置下预检、备份、迁移、切换和业务验收。
- 自动化检查不访问真实模型、生产数据或生产主机，公开报告明确区分“制品通过”与“生产通过”。
- 数据库备份、源二进制身份、排空、空间检查与故障恢复继续保留。
