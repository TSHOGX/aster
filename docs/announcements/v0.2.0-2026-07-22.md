# 系统更新公告 · v0.2.0(2026-07-22)

本次 **v0.2.0** 更新带来了会话管理、文件操作和数据分析三个方面的一批新能力,并修复了中文显示的一个老问题。以下是主要内容。

## 新增功能

### 会话管理更省心

- **会话自动命名**:新建会话发出第一条消息后,系统会自动为它生成一个简短、贴切的名字,左侧会话列表和顶部标题栏都会显示这个名字,不用再对着一串 `sess_` 开头的编号猜哪个是哪个
- **随时手动改名**:在左侧会话列表中双击会话名即可就地重命名,或点击每行右侧的 "..." 菜单选择"重命名";手动改过的名字不会再被自动命名覆盖
- **历史会话已补齐名字**:你之前创建的会话也已统一生成好名字,打开就能看到
- **会话搜索上线**:按 **⌘P**(Mac)或 **Ctrl+P**(Windows/Linux),或点击左上角的搜索图标,即可一键搜索所有历史会话——会话标题、你发送的消息、助手的回复都能全文检索,支持中文和任意语言的任意片段匹配。结果按相关度排序并高亮匹配内容,点击某条消息会直接打开对应会话并滚动定位到那条消息;不输入关键词时面板会列出最近的会话,方便快速切换。搜索仅限于你自己的会话

### 文件上传与在线编辑

- **上传文件**:文件面板新增上传入口,支持一次选择多个文件、上传整个文件夹(保留子目录结构),或直接把文件/文件夹拖拽进面板。上传的文件会立即出现在文件树里,智能体在下一轮对话中就能读到,单个文件上限 100MB
- **在线编辑**:打开代码、Markdown、JSON 等文本文件后,预览区右上角会出现"编辑"按钮,点击即可直接修改并保存,改动会同步进工作区供智能体使用;若智能体在你编辑期间也改动了同一个文件,保存时会提示你先刷新,避免覆盖它的最新结果
- 上传和在线编辑仅在**当前没有对话正在进行**时可用;编辑面向 1MB 以内的文本文件,图片、PDF 等仍为只读预览

### 数据分析与办公能力大幅增强

- **数据分析能力大幅增强**:智能体现在可以直接读写 Parquet 列存文件、用 DuckDB 跑 SQL 查询、读写 Excel 表格,并支持 SciPy / StatsModels 等科学计算与统计分析,处理大数据集和复杂分析任务更加得心应手
- **一键生成办公文档**:新增生成 PDF、Word(.docx)、PowerPoint(.pptx)的能力,让智能体可以把分析结果直接整理成可交付的报告、文档和演示文稿
- **更丰富的图表样式**:在原有绘图基础上新增 Seaborn 和 Plotly,统计图表更美观,并支持导出为高清图片

## 体验与稳定性优化

- **中文等宽字体显示修复**:此前代码块、表格等等宽字体场景下中文会显示为方块乱码,现已彻底修复;同时补充了更完整的中文字体(含中文衬线体),文档和图表中的中文显示更清晰、更专业
- **会话列表更清爽**:列表每行改为"名字为主 + 状态"的展示,去掉了多余的模式标签,更容易一眼扫到目标会话

祝使用愉快。
