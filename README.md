# Aster

Aster is a workspace for AI conversations, terminals, files, and scheduled work.
Organize related work in a **Project**: its conversations and terminals share files,
and work continues when you close the browser. Files and conversation history
remain available when project compute is paused.

- **Using Aster:** start with [your first project](docs/users/getting-started.md).
- **Administering a workspace:** manage [accounts and access](docs/admin/accounts.md),
  [resources](docs/admin/resources.md), and [project operations](docs/admin/projects.md).
- **Running an installation:** follow [installation](docs/operators/installation.md),
  [configuration](docs/operators/configuration.md), and [maintenance](docs/operators/maintenance.md).
- **Publishing reusable files:** use [Volume Studio](docs/admin/volume-studio.md).

The [documentation index](docs/README.md) lists all guides and reference pages.
Your administrator controls which features and resources are available. The
installation may use your organization's name in place of Aster.

Aster runs on Linux with the Khora sandbox engine. An installation uses one
active application owner and persistent project storage. Check
[deployment compatibility](docs/reference/compatibility.md) before upgrading;
historical Aster databases are not automatically migrated.
